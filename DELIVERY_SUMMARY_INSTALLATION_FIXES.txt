THREE BUGS IDENTIFIED AND FIXED:

Bug #1: Wrong MCP Server Filename
  ├─ Problem: Script looked for "harness_mcp_server_v2.py" (v2) instead of "harness_claude_advanced_mcp.py" (v3)
  ├─ Impact: Installation would fail with "file not found" error
  └─ Fixed: Updated script to use correct v3.0.0 filename

Bug #2: Environment Variable Passing Failure  
  ├─ Problem: Python subprocess couldn't access bash environment variables
  ├─ Root Cause: Variables weren't exported before calling Python
  ├─ Impact: Python received empty string, resulting in FileNotFoundError
  └─ Fixed: Added explicit export statements and changed Python to use os.environ.get()

Bug #3: Rust/LLVM Incompatibility (macOS)
  ├─ Problem: Homebrew Rust 1.93.1 incompatible with LLVM 22.1.7
  ├─ Root Cause: Versions compiled against different LLVM libraries
  ├─ Impact: `pip install mcp` fails when compiling cryptography package
  └─ Fixed: Auto-detect issue, use environment variables to avoid compilation, use pre-built wheels
