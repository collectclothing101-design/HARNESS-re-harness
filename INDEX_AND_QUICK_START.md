## 🚀 Quick Start (5 Minutes)

### Download All Files
Files are available at: `/mnt/user-data/outputs/`

Required files:
- `HARNESS_SKILL_v2.md`
- `harness_mcp_server_v2.py`
- `install_harness.ps1` or `.bat` or `.sh`
- `HARNESS_v2_COMPLETE_DOCUMENTATION.md`

### Install (Choose Your Platform)

**Windows (PowerShell - Recommended)**:
```powershell
# Right-click PowerShell, select "Run as Administrator"
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\install_harness.ps1
```

**Windows (Batch)**:
```cmd
# Right-click Command Prompt, select "Run as Administrator"
install_harness.bat
```

**macOS/Linux**:
```bash
bash ./install_harness_universal.sh
```

### Verify

After installation, in Claude:
```
/harness_status
```

Should show:
```
"status": "operational"
"version": "2.0.0"
```

### Start Using

```
/design_agent_team
/validate_team_architecture
/optimize_team_performance
/create_wix_agent_scaffold
```

Or just type naturally:
```
"Design a multi-agent team for product recommendation"
```

## 🚨 Troubleshooting

### Installation Won't Run
- Ensure running as Administrator (Windows)
- Check Python installed: `python --version`
- Check Git installed: `git --version`

### Plugin Not Appearing
- Restart Claude completely (not just minimize)
- Wait 10 seconds after restart
- Type `/mcp` to verify connection
- Check config file exists

### Validation Fails
- Review the specific failed checks
- Address recommendations
- Re-run validation
- Consult examples in documentation

### Performance Issues
- Run `/harness_advanced_diagnostics`
- Check 2GB+ RAM available
- Run `/optimize_team_performance`
- Implement suggestions
