## How to Use

### As a /skill

```
/skill harness
```

Then ask Claude:
```
"Design a multi-agent team for [domain]"
"Generate a skill from this team"
"Add [system] integration"
"Analyze security"
```

### As a /plugin

```
/plugin install harness
```

Or create custom plugins:
```
/create_plugin_scaffold my-agent agent python
```

### Natural Language

Just describe what you need:
```
"Design a production-ready multi-agent team for customer feedback analysis
using the expert pool pattern. Include 5 specialized agents, comprehensive
testing, Slack integration, and deployment guide."
```
