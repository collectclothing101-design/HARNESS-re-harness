## 🎓 WHAT IS PEP 668? (1-minute explanation)

Homebrew Python blocks pip to prevent system breakage:
```
pip install mcp  ← Blocked by PEP 668
  ↓
"externally-managed-environment" error
  ↓
Use venv or --break-system-packages instead
```

**Solution**: Use one of the 3 provided scripts (already handles this)
