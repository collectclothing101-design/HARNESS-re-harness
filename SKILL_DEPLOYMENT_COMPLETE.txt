THREE BUGS COVERED
================================================================================

BUG 1: WRONG MCP FILENAME (CRITICAL)
  Error: harness_mcp_server_v2.py not found
  Root Cause: Script looks for v2 filename, v3.0.0 uses harness_claude_advanced_mcp.py
  Fix: Use install_harness_v3_corrected.sh OR copy correct MCP file
  Coverage: SKILL.md "Bug 1" section + BUG_ANALYSIS.md full analysis

BUG 2: ENVIRONMENT VARIABLES NOT EXPORTED (CRITICAL)
  Error: FileNotFoundError: [Errno 2] No such file or directory: ''
  Root Cause: Variables set but not exported to Python subprocess
  Fix: Add 'export' keyword to variable assignments in ~/.zprofile
  Coverage: SKILL.md "Bug 2" section + BUG_ANALYSIS.md full analysis

BUG 3: RUST/LLVM TOOLCHAIN MISMATCH (HIGH)
  Error: signal: 6, SIGABRT + Symbol not found: __ZN4llvm10PGOOptionsC1E
  Root Cause: Homebrew Rust compiled against different LLVM version
  Fix: brew reinstall rust OR use wheel-only pip install (3 options provided)
  Coverage: SKILL.md "Bug 3" section + BUG_ANALYSIS.md full analysis
