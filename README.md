## 🆘 QUICK TROUBLESHOOTING

| Issue | Fix |
|-------|-----|
| "mcp not found" | `pip install mcp` |
| Claude doesn't see tools | Restart Claude Desktop |
| Server won't start | Check Python 3.9+ with `python --version` |
| Wrong path errors | Update `HARNESS_DIR` environment variable |
| No metrics saved | Create `~/.local/share/ai-tools/harness/` |
